# 牧云羊场发布素材 · 一千万退休

- 封面：`cover-1080x1440.jpg`，1080×1440，3:4。主标题和木牌副标题均为「一千万退休」。
- 图标：`icon-512.png`，512×512；`icon-1024.png` 是大图备用版。没有附加文字，小尺寸仍能看清主体。
- 原尺寸成图：`cover-1102x1428.png`。封面中的特殊羊为绒糖金、薄荷绿、蜜桃粉、星愿紫和彩虹色，暖棕色脸与原有体素立体材质保留。

- 这些文件独立于游戏运行资源，不放进小工具代码包；代码包仍使用 v10。
