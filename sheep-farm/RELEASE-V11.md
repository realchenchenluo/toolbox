# v11 指引与操作修复

本次未调整价格、收入、奖励概率、退休目标或账号存档键。旧羊场保留原有进度；只有重新体验引导的按钮会重置指引步骤。

## 操作故障

- 待领取彩虹羊时，羊种商店引用了作用域外的 `loading`，导致渲染异常。已移到共用作用域，并覆盖待领取奖励的测试。
- 购羊、升级、订单和出栏列表每次刷新都会销毁按钮，按下与抬起之间遇到刷新时可能丢失点击。现在复用未变化的列表，按压期间延迟替换；羊与落地羊毛按 ID 复用节点。
- 同一付费按钮的 300ms 内重复点击只执行一次；仍由业务逻辑检查余额、等级、名额和货物。
- 原生读写与云同步增加 8 秒响应期限。云请求超时解除操作等待，过期响应不能覆盖后来进度；原生存档未读出时保持保护，可重试读取，不写入新档覆盖旧档。
- 原生写入超时后不发起重叠写入，队列可以返回失败；旧请求结束后允许下次保存。切换弹窗时丢弃前一个弹窗待执行的列表更新。

## 指引与手机布局

- 四步入门、参考发育路线、羊种能力、详细规则，可随时查看并重播操作指引。
- 左草右水各补一次，再剪毛、拾取、到集市出售。槽已满和雇工已代拾取时也能继续引导。
- 羊种展示解锁费、购买费、触发条件及使用建议，说明光环与永久开启入口的区别。
- 手机品牌与时钟同排，主界面在实际原生遮挡区域下面额外留 10px；弹窗仍保留 32px 间距、固定标题与 44px 关闭键。
