# 牧云羊场协作约定

- 用户要求每次更新或修复后给出已经核验可打开的最新预览链接，回复中把链接放在前面。复用可用的本地服务器，带版本查询参数区分更新；明确本机预览与线上发布的区别。
- 用户确认之前不生成或更新发布 ZIP。修改源文件并提供预览即可。
- 羊行走曾多次出现头身断开。现在行走使用完整 PNG，方向通过整体镜像改变；禁止恢复对背景图集位置进行插值的 CSS 动画。坐下、卧下、吃草、喝水、睡觉也使用独立完整图片。
- 羊种分普通/薄荷/蜜桃/彩虹，幼羊和成年羊使用不同模型。任何年龄都能长毛剪毛；60 日龄后才能出售活羊或获取羊肉，逻辑层同样需要拦截幼羊。
- 现金、累计收入、退休金分别存储。存钱必须扣现金并增加退休金，不能把累计收入直接当作已存退休金。
- 新功能遵循收入门槛、付费升级牧场、功能开放、付费解锁/购买的递进过程。迁移旧档要保留现金、羊群、已购升级与存档，不重置用户进度。
- 涉及存档、经济、等级或羊种改动时，运行 `node tests/farm-behavior.cjs` 和 `node tests/cloud-save.cjs`。浏览器用于本机交互和视觉检查，不能据此声称已完成小红书容器或 Android/iOS 真机验证。
- UI 方向为青青草原：浅蓝天空、起伏草坡、浅绿色面板，按钮与标签用柔和小圆角。草场占主要视野，退休存款放在管理面板的“账本”；顶部保留资源和游戏时钟。
- 羊脸统一暖棕色，幼羊使用窄脸与横向下垂耳朵；吃草和喝水不能切成白色脸。特殊羊只改变羊毛配色，脸型、脸色和各姿势需保持一致。
- 游戏时钟从 06:00 开始，18:00 入夜，次日 06:00 天亮；实际时间白天 48 秒、夜晚 12 秒。时钟必须跟随模拟阶段，附倒计时，只更新时钟控件而不高频重建羊群。
- 互动草由 `assets/interactive-grass.js` 绘制，采用独立草簇、脚底范围检测、整数像素逐行偏移和弹簧回弹。羊与雇工按脚底位置排序；不要裁切、擦除或分层重画羊的 PNG。草是装饰，不写入经济或存档状态。
- 修改互动草后运行 `node tests/interactive-grass.cjs`，并验证行走经过、离开恢复、夜色、缩放、后台返回与羊毛拾取。保持背景暂停、返回后单条动画循环。
- 新存档从第 0 天、300 金币、3 只幼羊开始；旧存档保持原有金额与羊数。顶部“玩法”随时可查看完整规则，存档读取期间也应可打开。
- 羊动作序列由 `tools/draw-sheep-sprite.py` 生成：16 套品种/年龄/毛态变体，每套 18 帧、7 个动作。运行时只切换完整 PNG 的 `img.src`；4 帧迈腿循环独立于寻路，不改经济时钟，不插值图集位置。
- 页面外层高度限制为视口，桌面管理区内部滚动，手机在 main 内滚动。升级分类字号保持至少 15px，长列表和弹窗不能撑大页面。
- 当前经济参数及模拟见 `ECONOMY-BALANCE.md`。补给价格固定，基础设施首级便宜，后续升级费递增；显示金额和实际扣费都使用统一费用函数。改经济运行 `node tests/economy-balance.cjs`，礼盒/订单不得低于原料和售盒收益。
