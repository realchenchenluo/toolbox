# 牧云羊场协作约定

- 用户要求每次更新或修复后给出已经核验可打开的最新预览链接，回复中把链接放在前面。复用可用的本地服务器，带版本查询参数区分更新；明确本机预览与线上发布的区别。
- 用户已授权本次 v7 最终小红书上传 ZIP。使用 tools/package-farm.py，仅打包入口和运行资源，包含24张羊图集与必要的完整羊像素兜底图，ZIP文件数必须≤200；不得把测试页、旧 ZIP 或说明文档塞进包里。
- 羊行走曾多次出现头身断开。行走显示完整32px PNG帧，方向通过整体镜像改变；禁止恢复对背景图集位置进行插值的 CSS 动画。坐下、卧下、吃草、喝水、睡觉也显示独立完整帧；允许用图集存储并以整数坐标还原完整帧，禁止在画面上插值裁切图集。
- 羊种按云朵/绒糖/薄荷/蜜桃/星愿/彩虹排列（LV1/2/4/5/6/8），幼羊和成年羊使用不同模型。任何年龄都能长毛剪毛；60 日龄后才能出售活羊或获取羊肉，逻辑层同样需要拦截幼羊。
- 现金、累计收入、退休金分别存储。存钱必须扣现金并增加退休金，不能把累计收入直接当作已存退休金。
- 新功能遵循收入门槛、付费升级牧场、功能开放、付费解锁/购买的递进过程。迁移旧档要保留现金、羊群、已购升级与存档，不重置用户进度。
- 涉及存档、经济、等级或羊种改动时，运行 `node tests/farm-behavior.cjs` 和 `node tests/cloud-save.cjs`。浏览器用于本机交互和视觉检查，不能据此声称已完成小红书容器或 Android/iOS 真机验证。
- UI 方向为青青草原：浅蓝天空、起伏草坡、浅绿色面板，按钮与标签用柔和小圆角。草场占主要视野，退休存款放在管理面板的“账本”；顶部保留资源和游戏时钟。
- 羊脸统一暖棕色，幼羊使用窄脸与横向下垂耳朵；吃草和喝水不能切成白色脸。特殊羊只改变羊毛配色，脸型、脸色和各姿势需保持一致。
- 游戏时钟从 06:00 开始，18:00 入夜，次日 06:00 天亮；实际时间白天 48 秒、夜晚 12 秒。时钟必须跟随模拟阶段，附倒计时，只更新时钟控件而不高频重建羊群。
- 互动草由 `assets/interactive-grass.js` 绘制，采用独立草簇、脚底范围检测、整数像素逐行偏移和弹簧回弹。羊与雇工按脚底位置排序；不要在画面上裁切、擦除或分层重画羊的 PNG。草是装饰，不写入经济或存档状态。
- 修改互动草后运行 `node tests/interactive-grass.cjs`，并验证行走经过、离开恢复、夜色、缩放、后台返回与羊毛拾取。保持背景暂停、返回后单条动画循环。
- 新存档从第 0 天、300 金币、3 只幼羊开始；旧存档保持原有金额与羊数。顶部“玩法”随时可查看完整规则，存档读取期间也应可打开。
- 羊动作序列由 `tools/draw-sheep-sprite.py` 生成：24 套品种/年龄/毛态变体，每套 18 帧、7 个动作。`sheep-frames.js` 从图集按整数32px区域还原完整PNG到内存，运行时只切换完整帧 `img.src`；4 帧迈腿循环独立于寻路，不改经济时钟，不插值图集位置。
- 页面外层高度限制为视口，桌面管理区内部滚动；手机只让 main 滚动，侧面功能区不再单独限高或滚动。升级分类字号保持至少 15px，长列表和弹窗不能撑大页面。
- 当前经济参数及模拟见 `ECONOMY-BALANCE.md`。补给价格固定，基础设施首级便宜，后续升级费递增；显示金额和实际扣费都使用统一费用函数。改经济运行 `node tests/economy-balance.cjs`，礼盒/订单不得低于原料和售盒收益。

- 满意度产毛加成为每点 0.1%、长毛 0.05%，最多 10%/5%。绒糖羊首次购入永久开启礼盒，星愿羊首次购入永久开启订单特殊奖励。彩虹羊 LV8，成长速率为普通羊一半。
- 订单奖概率只在符合等级、已完成15单、间隔40单且无其他稀有单时生效：羊圈+2为0.6%，彩虹名额+1为0.15%（初始2、最高5），LV8彩虹羊仔3%。每个订单有持久ID，读档不重新抽取，重复提交不能发奖。
- 基础羊圈上限20，订单扩容另加。满圈奖励羊仔暂存，不丢失；奖励羊仔不直接解锁商店。旧档超额羊不删除，后续购买受当前名额限制。
- 补给价格随LV1–8为2/3/6/15/50/150/500/2000，容量与每格补给同步扩大。特殊精料从500/800起，限时、不叠加、随等级涨价。退休目标为实际存入5000万。
- 出栏支持多选批量操作，未卖完成年羊时保留弹窗，全部成年羊出栏后关闭。手机弹窗 grid 列必须 minmax(0,1fr)，避免530px内容撑出屏幕。
- 新增综合测试：node tests/orders-and-tutorial.cjs、node tests/production-budget.cjs，所有羊素材检测：python tests/sheep-art.py。打包后审计目录及ZIP，并用包内同一文件验证图片加载与手机滚动。

- v8上传包精简为75文件（上限200），只打包24张sequence图集、24张idle兜底图、1张新手坐姿图与其他运行资源；原始432帧留在源码。解帧每次先清空32px画布，不改变身体位置，失败时显示完整idle羊。运行 node tests/sheep-frames.cjs 验证24次加载、432帧坐标、透明清理、缓存和兜底。

- visualViewport变化调整可用高度；自动聚焦只允许main/弹窗正文滚动，外层html/body程序性滚动应归零。用node tests/viewport-layout.cjs验证原生按钮/胶囊/横屏/输入布局计算；本机模拟顶部覆盖不等于Android/iOS真机验收。
