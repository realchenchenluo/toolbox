# 牧云羊场

一款像素风养羊经营小游戏：回乡继承羊场，照顾小羊、剪毛拾取、售卖货物，逐步升级牧场与羊种，亲手攒够1000 万元退休金。

[在线试玩](https://realchenchenluo.github.io/toolbox/sheep-farm/?v=20261125-guide-11)

## 当前玩法

- 新玩家从第 0 天、300 金币和 3 只普通幼羊开始，已有存档保留进度。
- 点击两侧干草槽、水槽付费补给；羊会走近吃喝，也会坐下、卧下和睡觉。
- 幼羊、成年羊均能长毛剪毛，落地羊毛需拾取后到集市出售；雇工可帮助搬运，60 日龄后才可出栏。
- 等级收入门槛、付费升级、设施购买和特殊羊种购买逐步开放；薄荷羊、蜜桃羊、彩虹羊有独立能力。
- 基础补给保持低价，后续设施费用递增；加工礼盒与订单保留相对原料的收益。
- 白昼 48 秒、夜晚 12 秒，顶部显示时钟与倒计时；草簇随羊和雇工经过弯曲回弹。
- 草场标题栏“玩法”可查规则；每 12 秒自动保存，也可手动保存。退休金存入时扣除等额现金。

## 运行

在仓库根目录执行：

```sh
python -m http.server 8090
```

打开 `http://localhost:8090/sheep-farm/`。游戏使用本地 HTML、CSS、JavaScript 和图片，无需安装前端依赖。普通网页保存到当前浏览器；平台容器下使用平台存储，云存档需相应平台能力和权限。不同网站域名的本机存档独立。

## 目录

- `index.html`、`assets/`：网页运行文件。
- `tests/`：游戏行为、账号存储、经济、互动草与像素素材检查。
- `tools/`：项目原创素材生成与预览脚本。

GitHub `main` 保存源码；`gh-pages` 的 `/sheep-farm/` 保存在线试玩静态文件。

## 当前经营规则

- 首次进入有四步说明与四步实操指引，老存档不强制重看。手机端主内容统一滚动。
- 云朵羊 LV1、绒糖羊 LV2、薄荷羊 LV4、蜜桃羊 LV5、星愿羊 LV6、彩虹羊 LV8。绒糖羊首次购入永久开启礼盒，星愿羊首次购入永久开启订单特殊奖励。
- 原料订单 LV3 同时两张，LV5 三张。满意度每点增加产毛 0.1%、长毛速度 0.05%，最多 +10% / +5%。
- 特殊奖励在符合条件的交付刷新中抽取：羊圈名额 +2 为 0.6%，彩虹名额 +1 为 0.15%（初始 2，最高 5），LV8 后彩虹羊仔为 3%。至少先完成 15 单，同场最多一张稀有单，领奖后至少间隔 40 单。具体货物量与概率说明在游戏“玩法”中。
- 基础羊圈可扩至 20 只，订单名额可超过 20。彩虹羊长大耗时翻倍；高价精料限时生效、同类不叠加。
- 草、水单格费用依等级为 2 / 3 / 6 / 15 / 50 / 150 / 500 / 2000 金币，槽容量与单格补充量同步扩大。
- 出栏支持多选批量操作，保留窗口供继续选择；无成年羊时自动关闭。

## v8 文件数修复

上传包从625项降至75项，约156KB，打包强制检查不超过200文件。原始432帧仍保留在素材源码；上传使用24张图集，加载后以整数32px裁切还原完整PNG帧到内存，显示整只羊并整体镜像转身。图集不做CSS位置插值，图片加载或Canvas不可用时显示完整待机羊。存档、价格和玩法沿用v7。

## v9手机适配

页面与全部弹窗按小红书getWindowInfo实际返回的安全区、独立按钮或胶囊位置避让。关闭按钮固定44×44px，正文独立滚动；输入聚焦与可用视口变化不会把保存按钮推到顶部遮挡区。API缺失时保留安全区与顶部留白。上传包76文件，仍低于200上限。

## v10布局与搬运

页面和所有弹窗统一增加32px顶部间距，玩法与保存移动到草场标题栏。窗口按钮尚未完成布局时保留安全留白，页面加载后重测。退休目标调整到实际存入1000万，旧存款全额保留。雇工移动速度翻倍，每趟容量4/6/8/10堆，每次可拾脚边40px内最多2堆羊毛，入棚后才入库。

## v11引导与操作修复

玩法分为四步入门、发育路线、羊种能力、详细规则，可重播实际操作指引。指导文字移到草场上方，羊种商店可展开使用建议。手机品牌与时钟合并一行，主界面额外顶部间距减到10px；弹窗仍保留32px安全间距和固定44px关闭键。

购羊、升级、订单、出栏列表保留未变化的DOM，按住期间延迟更新；羊毛节点不再随定时刷新销毁。购入双击去重，待领取彩虹羊不再触发loading变量异常。读/写/云存储响应超时返回明确反馈，可重试读档，未读档不覆盖旧档；原生写入未结束时不发起重叠写入。经济参数、奖励概率和目标保持v10。

`python tools/prepare-ui-check.py`生成只供本机的浏览器测试页；运行本地服务后访问给出的URL，点击“运行按钮回归测试”，覆盖60个UI检查。测试夹具与测试羊场不进入代码包。
